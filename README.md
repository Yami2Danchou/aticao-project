# 🌱 AtiCao – AI-Powered Cacao Disease Detection System

AtiCao is an AI-powered mobile application designed to assist cacao farmers in the Philippines, especially in Davao, by detecting cacao pod diseases and providing science-based, actionable farming recommendations.

It combines **Artificial Intelligence**, **IoT environmental monitoring**, and **agricultural science** to help improve cacao production and reduce crop losses.

---

## 📱 Features

### 🤖 AI Disease Detection

* Detects **Black Pod Rot** and **Cacao Pod Borer**
* Uses dual models (Alpha & Beta) for improved accuracy
* Displays real-time confidence scores

### 🌿 Severity-Based Recommendations

* Provides action plans based on severity:

  * Mild
  * Moderate
  * Severe
* Step-by-step farming guidance

### 📖 Visual Learning System

* Image-based instructions for farming activities:

  * Pruning
  * Sanitation
  * Pod removal
  * Rampasan

### 🌡️ IoT Environmental Monitoring (ESP32)

* Real-time tracking of:

  * Temperature
  * Humidity
  * Soil Moisture
* Helps predict disease risk conditions

### 🗂️ Scan History

* Stores past detections
* Includes:

  * Date & time
  * Disease type
  * Severity level
  * Image records
* Helps track farm health over time
